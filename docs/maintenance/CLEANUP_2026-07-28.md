# Workspace cleanup record: 2026-07-28

The cleanup was explicitly approved by the project owner. It removed reproducible caches, temporary downloads, obsolete build inputs, and generated interpreter caches while preserving research data, models, the active environment directory, and publication artifacts.

## Removed

- `.uv-cache` (approximately 5.02 GB)
- `.downloads` (approximately 2.59 GB)
- `.venv-official` (approximately 348 MB)
- `.npm-cache`, `.uv-cache-stage25`, `.pytest_cache`, `.ruff_cache`, and `.server`
- `artifacts`, `build-artoria-cinematic-assets.mjs`, and `.agents`
- `web/node_modules/.vite-temp`
- Python `__pycache__` directories and LaTeX intermediate files

The measured reclaimed space was approximately 8.17 GB.

## Preserved

- `.venv`
- `.artifacts`
- `models`
- `outputs`
- tracked paper sources, PDFs, figures, source data, and review records

During verification, the tracked `paper/` tree was found to have been removed unintentionally by the cleanup command. It was restored byte-for-byte from `HEAD` before any new paper edits were made. No cache directory or obsolete environment from the approved removal list was restored.

## Reproducibility impact

The removed directories contain reproducible or downloadable material and are not source-of-truth research evidence. The active `.venv` remains present, but its UV-managed base interpreter resides outside the repository and therefore may require normal UV environment repair on another machine. Dependency lock and project metadata remain authoritative.
