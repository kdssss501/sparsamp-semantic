# R054 共形边界证书研究合同

## 研究目的

R054 检验跨精度 token 分歧是否集中在公开整数采样边界附近。方法把离散决策裕量与 split conformal 校准结合，用留出轨迹自身的 FP16 参考合同构造证书，但构造时不读取留出轨迹的 BF16 目标选择。

这是单 GPU 的回顾性可行性研究，不构成跨硬件保证。共形覆盖陈述依赖 prompt 级可交换性。

## 冻结数据与划分

- 数据源：`outputs/R044_qwen_replay_scale.json`。
- 模型：Qwen2.5-1.5B-Instruct。
- 参考端/目标端：同一 RTX 3060 Laptop 环境中的 FP16/BF16。
- 合同：top-2、`q=0.5`、`T=1.2`、`B=16`。
- 校准集：偶数 prompt 索引 `0,2,...,18`。
- 留出集：奇数 prompt 索引 `1,3,...,19`。
- 每个 prompt 保留三个公开 seed。
- 主显著性水平：prompt 聚类层面的 `alpha=0.10`。

该划分在查看边界裕量结果前固定。两个分区均包含五个英文和五个中文 prompt。

## 分数与证书

对整数质量采样值 `s` 和内部累积边界 `b`，当 `b <= s` 时，无害方向位移为 `s-b`；当 `b > s` 时为 `b-s-1`。一步的裕量取所有内部边界的最小值。

一条轨迹的校准分数，是所有实际目标特定修正位置的最大裕量加一；没有修正时分数为零。一个 prompt 的分数取其三个 seed 的最大值。十个校准 prompt 上的共形半径取第 `ceil((n+1)(1-alpha))` 个顺序统计量。

对每条留出轨迹，参考端证书记录所有裕量严格小于校准半径的位置及其参考 token。目标端修正只在证书冻结后用于评估 false-safe。

## 预注册结果指标

- 主指标：留出 prompt 覆盖，即同一 prompt 的三条轨迹均没有 false-safe 修正。
- 主成本：留出证书负载相对完整 token 轨迹的比例。
- 次指标：轨迹覆盖率、false-safe 数量、证书密度、相对目标特定 SPRC 的膨胀，以及 `alpha={0.20,0.30,0.40}` 的固定 Pareto 点。

## 判定规则

- Strong GO：留出 prompt 覆盖 10/10，证书负载低于完整轨迹的 50%，且不超过目标特定 SPRC 的 2 倍。
- Pilot GO：留出 prompt 至少覆盖 9/10，且证书负载低于完整轨迹的 50%。
- NO-GO：覆盖少于 9/10，或证书负载达到完整轨迹的 50%。

只有当每个已观察目标修正都落在预计算歧义集合内时，才推断修正后的重放精确。R054 不重跑 GPU，因此验证状态为 `ANALYZED`，而不是 `VERIFIED`。
